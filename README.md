# CLI Number Guessing Game

A simple **command-line number guessing game with a point system**, built with **TypeScript and Node.js**.

This project was developed during my time at **PIAIC (Presidential Initiative for Artificial Intelligence and Computing)** as part of my early experimentation with building, packaging, and publishing **TypeScript-based CLI applications as npm packages**.

## About

CLI Number Guessing Game is an interactive terminal game where players attempt to guess a randomly generated number and earn points based on their performance.

The project was created as a practical exercise for learning TypeScript, implementing game logic, handling user input, and building an interactive command-line experience.

## Features

* Interactive number guessing gameplay
* Random number generation
* Point-based scoring system
* Interactive command-line prompts
* Styled terminal output
* Loading animations
* Terminal-based visual effects
* Runs directly through `npx`

## Usage

The published package can be run directly using:

```bash
npx adil-number-guess
```
